Welcome to TurfGo

System Overview

TurfGo is a web-based sports arena and turf management platform designed to automate turf booking, slot scheduling, player check-in verification, and revenue management.

This version contains all pages in pure HTML and HTML forms with no CSS, JavaScript, PHP, or database dependencies.
